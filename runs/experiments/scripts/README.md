# Experiment runner scripts

Bash wrappers for `Run-MetaMatchPipeline.ps1` and grid tools. Run from **repo root**:

```bash
bash runs/experiments/scripts/run_hyperparam_sweep.sh
bash runs/experiments/scripts/run_grid_phase2_tmux.sh
bash runs/experiments/scripts/run_phase2.sh
```

See [../README.md](../README.md) for presets, comparison CSVs, and the current winner (`penalty300_min700_cap22_queryv2`).
